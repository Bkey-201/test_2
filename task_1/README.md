Анализ и модификация XML-аннотаций

Скрипты для обработки XML-файлов аннотаций в формате CVAT.

## Зависимости
- Python 3.6+
- Стандартная библиотека (xml.etree.ElementTree, os, sys, collections)

## Использование

Все скрипты принимают имена XML-файлов как аргументы командной строки.  
Если аргументы не указаны, по умолчанию обрабатываются:
- `annotations.xml`
- `annotations-2.xml`
- `annotations-3.xml`

### 1. Общая статистика
```bash
python stats_total.py [файлы.xml ...]

Как использовать

1. Поместите все четыре скрипта и этот README в папку `task1`.
2. Убедитесь, что XML-файлы (`annotations.xml`, `annotations-2.xml`, `annotations-3.xml`) находятся в той же папке (или укажите пути к ним при запуске).
3. Запускайте нужные скрипты из командной строки.

Все скрипты работают независимо и не требуют установки дополнительных библиотек.

1. stats_total.py – общая статистика
Выводит:

Общее количество изображений.

Количество размеченных (есть хотя бы одна фигура любого типа).

Количество неразмеченных.

Общее количество фигур (суммарно по всем файлам).

Размер (ширина, высота) и название самого большого и самого маленького изображения (по площади). Если таких несколько – выводится количество и параметры любого одного.


2. stats_classes.py – статистика по классам
Выводит для каждого уникального label (атрибут фигуры) количество фигур с этим классом.


3. stats_types.py – статистика по типам фигур (опционально)
Выводит количество фигур каждого типа (box, polygon, points) независимо от класса.



4. modify_xml.py – модификация XML-файлов
Вносит два изменения в каждый переданный XML-файл:

Переворот id – элементы <image> сортируются по текущему id, затем им присваиваются новые идентификаторы в обратном порядке (первый получает максимальное значение, последний – минимальное).

Изменение name – удаляется путь (остаётся только имя файла), расширение заменяется на .png.

Результат сохраняется в новый файл с суффиксом _modified (например, annotations_modified.xml).
Исходные файлы не изменяются.
